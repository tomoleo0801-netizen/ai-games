# トモヤAI自由研究室のゲーム

AI（Claude Code）が作ったミニゲームを置いています。スマホでもパソコンでも、ブラウザで遊べます。

- 入口のページ：`index.html`
- シューティングの試作（`tsubame/` 縦、`hoshikaze/` 横、`hanabi/` 撃ち落とす）：どれも3つのステージとボス。AI が自動で遊んで最後まで行けることは確かめた。人が遊んでの調整はまだ。
- 芽を育てるミニゲーム（`1/`〜`4/`）：同じ頼み方で作った10本のうち、遊んで面白かった上位4本。AI が作ったままで、人の手では直していません。

どのゲームも `index.html` 1つで動き、外から画像、音、フォント、ライブラリを読み込みません。
